# Checklist υφιστάμενων λειτουργιών

Εκτελείται ΠΡΙΝ και ΜΕΤΑ από κάθε φάση του `ui-v6`. Ο αυτόματος έλεγχος είναι το `tests/features.js` (`NODE_PATH=$(npm root -g) node tests/features.js`)·
τα στοιχεία με ✋ ελέγχονται χειροκίνητα (μόνο σε πραγματική συσκευή/λογαριασμό).

| Κωδ. | Λειτουργία | Έλεγχος |
|---|---|---|

| B1 | Φίλτρα αθλημάτων στα Νέα (Όλα/Ποδόσφαιρο/Μπάσκετ/Ερασιτέχνης) | αυτόματος |
| B2 | «Τα βασικά σήμερα» | αυτόματος |
| B3–B5 | Λίστα ειδήσεων, άνοιγμα με πλήρες κείμενο, σύνδεσμος πηγής | αυτόματος |
| B6 | Ενότητα «Πρόγραμμα» | αυτόματος |
| B7 | Ένδειξη «Powered by SportScore» | αυτόματος |
| B8–B9 | Φίλτρο αθλήματος δείχνει μόνο το άθλημα και αποθηκεύεται (`thr_f`) | αυτόματος |
| B10 | Κάρτα επόμενου αγώνα / live (#next) | αυτόματος |
| C1–C4 | Αγώνες: Επόμενοι/Αποτελέσματα, κάρτες, σκορ | αυτόματος |
| D1 | Live: κάρτα αγώνα ή κενή κατάσταση | αυτόματος |
| J1–J11 | Live Center: μπάρα ενημέρωσης, φίλτρα κατάστασης/αθλήματος/διοργάνωσης (συνδυασμοί, καθαρισμός), χωρίς overflow, Powered by SportScore | αυτόματος |

| F0–F12 | «Κι άλλα»: 10 ενότητες (βαθμολογίες, σκόρερ, τιμωρίες, μεταγραφές, δηλώσεις, Ερασιτέχνης, αρχείο, αντίπαλοι, στοίχημα, chat) και αναζήτηση αρχείου | αυτόματος |
| G1–G5 | 5 κουμπιά κάτω μπάρας, πλοήγηση με hash, manifest/apple-touch-icon, service worker, θέμα | αυτόματος |
| H1 | Κανένα σφάλμα JavaScript | αυτόματος |
